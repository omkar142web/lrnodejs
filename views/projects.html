This Website — KNOWLEDGE_BASE

A living system for learning in public — not a portfolio, a process.

Built from scratch using only HTML, CSS, and vanilla JavaScript. No frameworks. No shortcuts. Every design decision was deliberate — a way of proving I understand the foundations before reaching for abstractions. The goal wasn't to ship a site; it was to understand what a site actually is.

HTML5 CSS3 Vanilla JS Google Fonts API CSS Custom Properties IntersectionObserver
Mobile overflow from absolutely-positioned blobs took an embarrassingly long time to fix. Learnt that overflow: hidden on body alone doesn't clip on mobile WebKit — you need it on html too. Also: 100dvh vs 100vh matters more than I expected on iOS Safari. Everything took 3× longer than planned. That's the point.
